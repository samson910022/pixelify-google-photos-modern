Pixelify Infinity

獨立維護的 Xposed 模組，可針對 Google 相簿（Google Photos） 模擬特定 Google Pixel 裝置屬性與系統功能旗標。 使用現代 libxposed API，並擁有獨立的套件名稱、版本歷史與簽署身分。

GitHub Releases Xposed Modules Repo LSPosed 列表
重要

本專案與 Google、Google 相簿、Pixel、LSPosed 或原始上游維護者沒有隸屬或背書關係。 功能可能隨 Google 相簿、伺服器端設定、帳戶、地區、裝置或 Android 更新而改變。 使用風險由使用者自行承擔。

功能

  • 全新 Material 3 現代化介面，支援動態取色與雙介面切換（可自由切換現代／經典 UI）。
  • 首次使用新手導引流程，說明預設 Pixel XL 無限備份並提供一鍵強制停止作用中應用程式與啟動 Google 相簿。
  • 模擬特定 Google Pixel 裝置設定檔（涵蓋 Pixel XL、Pixel 6、Pixel Fold、Pixel Tablet、Pixel 9 Pro Fold 至 Pixel 10 系列共 30 種設定檔）。
  • 即時顯示各機型對應之備份權益標籤與畫質要求警告提示。
  • 模擬與 Pixel 相關的系統功能旗標。
  • 多層級泛用退避偽裝管線，相容 Android 8.0 至 Android 14、15、16+ 及各式深度客製 OEM ROM。
  • 可選擇模擬相容的 Android 版本。
  • 覆寫 ROM 內建的 Pixel feature level。
  • 透過進階設定個別選擇功能旗標。
  • 匯入、匯出及分享模組設定。
  • 應用內診斷畫面：顯示模組啟用狀態、備份權益狀態、Hook 里程碑與上次裝置模擬 VERIFY 結果，無需 logcat；可一鍵複製不含帳號資料的診斷報告。

裝置設定檔與備份權益說明

依據 Google 的相簿雲端儲存政策，不同世代的 Pixel 機型享有不同的備份權益與功能：

設定檔層級 適用機型 Google 相簿備份權益 所需相簿備份畫質設定 解鎖功能層級
無限制原始畫質 Pixel XL （預設） 永久免費無限制備份（原始畫質與省儲存空間皆不佔空間） 原始畫質 或 省儲存空間 Pixel 2016 基礎層級（最穩定享有無限空間；無 Tensor AI 工具）
僅限無限制省儲存空間 Pixel 2, Pixel 3 XL, Pixel 3a XL, Pixel 4 XL, Pixel 4a, Pixel 5, Pixel 5a 僅限「省儲存空間（高畫質）」享有免費無限制備份 必須設定為「省儲存空間」（若設為原始畫質會扣除帳號空間！） 中階 Pixel 功能旗標
僅解鎖相片編輯功能 Pixel 6 至 Pixel 10 系列、Pixel Fold、Pixel Tablet 無免費無限制備份（所有上傳皆正常扣除 Google 帳號空間） 所有畫質皆會扣除雲端空間 最新 Pixel 相機與 AI 相片編輯功能（魔術橡皮擦、Ultra HDR、肖像光影等）
重要提示

若您的主要目的是獲得免費無限制的相簿空間，請務必選擇 Pixel XL（原始畫質）或 Pixel 2 至 Pixel 5a（畫質設為省儲存空間）。選擇 Pixel 6 或更新機型將不會享有免費相簿空間。

如何確認備份是否成功

您可以透過以下兩種方法確認裝置模擬與免費備份是否正常生效：

方法一：檢查 Google 相簿備份設定

  1. 開啟 Google 相簿。
  2. 點選右上角個人頭像 > 備份。
  3. 點選右上角齒輪圖示（備份設定）。
  4. 確認橫幅是否顯示：「這部 Pixel 可免費備份無限量的相片和影片」。

方法二：實際上傳相片並檢查詳細資料

  1. 在 Google 相簿中實際上傳備份一張相片／影片。
  2. 點開該相片並向上滑動查看詳細資訊（或在 photos.google.com 查看）。
  3. 確認儲存空間資訊顯示：「這個項目不佔用你的帳戶儲存空間」（使用 0 個位元組）。

疑難排解：若相片上傳後仍顯示扣除空間，請至本 App 的「診斷」畫面確認 VERIFY 成功、確認 Pixel 2–5 已設為省儲存空間畫質，並點擊「強制停止作用範圍 App」或清除 Google 相簿快取。

系統需求

  • Android 8.0（API 26）以上。
  • Root 權限。
  • 支援現代 libxposed API 101 的 Xposed 環境，例如相容的 LSPosed 設定。
  • Google 相簿（com.google.android.apps.photos）。

此現代 API 版本不支援舊式 XposedBridge／EdXposed 環境。 請將 Google 相簿納入模組作用範圍（建議）。其他 App 屬進階且不支援，並有風險。 請勿將 Play 服務、Play 商店、系統 UI／設定或銀行／支付 App 納入作用範圍 （即使勾選，模組也會 soft-denylist 其中數項）。

安裝

  1. 從本 repository 的 Releases 頁面（或官方 Xposed Modules Repository 鏡像）下載 APK。
  2. 安裝 APK。
  3. 在 Xposed 模組管理器啟用 Pixelify Infinity。
  4. 將 Google 相簿納入模組作用範圍（建議）。 允許多 App 作用範圍，但其他 App 屬進階且不支援。
  5. 請勿將 Play 服務、Play 商店、系統 UI／設定或銀行／支付 App 納入作用範圍。
  6. 強制停止並重新開啟 Google 相簿（以及任何其他已納入作用範圍的 App）；若模組管理器要求，請重新啟動裝置。

安裝前請確認簽署者指紋與 docs/RELEASE_SIGNING.md 公布的內容相符。正式版本使用固定簽署憑證；私密簽署金鑰不會放入此 repository。
