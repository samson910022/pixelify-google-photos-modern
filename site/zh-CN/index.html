Pixelify Infinity

独立维护的 Xposed 模块，可为 Google 相册（Google Photos） 模拟部分 Google Pixel 设备属性与系统功能标志。 使用现代 libxposed API，并拥有独立的软件包名称、版本历史和签名身份。

GitHub Releases Xposed Modules Repo LSPosed 列表
重要

本项目与 Google、Google 相册、Pixel、LSPosed 或原上游维护者没有隶属或背书关系。 功能可能随 Google 相册、服务端配置、账号、地区、设备或 Android 更新而变化。 使用风险由用户自行承担。

功能

  • 全新 Material 3 现代化界面，支持动态取色与双界面切换（可自由切换现代／经典 UI）。
  • 首次使用新手引导流程，说明默认 Pixel XL 无限备份并提供一键强行停止作用域应用与启动 Google 相册。
  • 模拟特定 Google Pixel 设备配置（涵盖 Pixel XL、Pixel 6、Pixel Fold、Pixel Tablet、Pixel 9 Pro Fold 至 Pixel 10 系列共 30 种配置）。
  • 实时显示各机型对应的备份权益标签与画质要求警告提示。
  • 模拟与 Pixel 相关的系统功能标志。
  • 多层级通用回退伪装管线，兼容 Android 8.0 至 Android 14、15、16+ 及各类深度定制 OEM ROM。
  • 可选模拟兼容的 Android 版本。
  • 覆盖 ROM 提供的 Pixel feature level。
  • 在高级设置中单独选择功能标志。
  • 导入、导出和分享模块配置。
  • 应用内诊断界面：显示模块启用状态、备份权益状态、Hook 里程碑与上次设备伪装 VERIFY 结果，无需 logcat；可一键复制不含账号数据的诊断报告。

设备配置与备份权益说明

根据 Google 的相册云存储政策，不同世代的 Pixel 机型享有不同的备份权益与功能：

配置层级 适用机型 Google 相册备份权益 所需相册备份画质设置 解锁功能层级
无限制原始画质 Pixel XL （默认） 永久免费无限制备份（原始画质与省空间画质均不占空间） 原始画质 或 省空间画质 Pixel 2016 基础层级（最稳定享有无限空间；无 Tensor AI 工具）
仅限无限制省空间画质 Pixel 2, Pixel 3 XL, Pixel 3a XL, Pixel 4 XL, Pixel 4a, Pixel 5, Pixel 5a 仅限「省空间画质（高画质）」享有免费无限制备份 必须设置为「省空间画质」（若设为原始画质会扣除账号空间！） 中阶 Pixel 功能标志
仅解锁相片编辑功能 Pixel 6 至 Pixel 10 系列、Pixel Fold、Pixel Tablet 无免费无限制备份（所有上传均正常扣除 Google 账号空间） 所有画质均会扣除云端空间 最新 Pixel 相机与 AI 相片编辑功能（魔术橡皮擦、Ultra HDR、肖像光影等）
重要提示

若您的主要目的是获得免费无限制的相册空间，请务必选择 Pixel XL（原始画质）或 Pixel 2 至 Pixel 5a（画质设为省空间画质）。选择 Pixel 6 或更新机型将不会享有免费相册空间。

如何确认备份是否成功

您可以通过以下两种方法确认设备模拟与免费备份是否正常生效：

方法一：检查 Google 相册备份设置

  1. 打开 Google 相册。
  2. 点击右上角个人头像 > 备份。
  3. 点击右上角齿轮图标（备份设置）。
  4. 确认横幅是否显示：“这台 Pixel 可免费备份无限量的照片和视频”。

方法二：实际上传照片并检查详细信息

  1. 在 Google 相册中实际上传备份一张照片／视频。
  2. 打开该照片并向上滑动查看详细信息（或在 photos.google.com 查看）。
  3. 确认存储空间信息显示：“此内容不占用您的账号存储空间”（使用 0 字节）。

疑难排解：若照片上传后仍显示扣除空间，请前往本应用的「诊断」界面确认 VERIFY 成功、确认 Pixel 2–5 已设为省空间画质，并点击「强行停止作用域 App」或清除 Google 相册缓存。

系统要求

  • Android 8.0（API 26）或更高版本。
  • Root 权限。
  • 支持现代 libxposed API 101 的 Xposed 环境，例如兼容的 LSPosed 配置。
  • Google 相册（com.google.android.apps.photos）。

此现代 API 版本不支持旧式 XposedBridge／EdXposed 环境。 请将 Google 相册纳入模块作用域（推荐）。其他 App 属于高级且不支持，并有风险。 请勿将 Play 服务、Play 商店、系统 UI／设置或银行／支付 App 纳入作用域 （即使勾选，模块也会 soft-denylist 其中若干项）。

安装

  1. 从本仓库的 Releases 页面（或官方 Xposed Modules Repository 镜像）下载 APK。
  2. 安装 APK。
  3. 在 Xposed 模块管理器中启用 Pixelify Infinity。
  4. 将 Google 相册纳入模块作用域（推荐）。 允许多 App 作用域，但其他 App 属于高级且不支持。
  5. 请勿将 Play 服务、Play 商店、系统 UI／设置或银行／支付 App 纳入作用域。
  6. 强制停止并重新打开 Google 相册（以及任何其他已纳入作用域的 App）；如果模块管理器要求，请重启设备。

安装前请确认签名者指纹与 docs/RELEASE_SIGNING.md 公布的内容一致。正式版本使用固定签名证书；私有签名密钥不会存放在此仓库中。
