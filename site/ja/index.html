Pixelify Infinity

Google フォト（Google Photos）に対して一部の Google Pixel 端末プロパティと システム機能フラグを偽装する、独立メンテナンスの Xposed モジュールです。 Modern libxposed API を使用し、独自のパッケージ名・リリース履歴・署名 ID を持ちます。

GitHub Releases Xposed Modules Repo LSPosed 一覧
重要

本プロジェクトは Google、Google フォト、Pixel、LSPosed、または元の上流メンテナーとは 提携しておらず、承認も受けていません。 機能の利用可否は、Google フォト、サーバー側の設定、アカウント、地域、端末、Android の更新によって変わる可能性があります。 自己責任で使用してください。

機能

  • 新しい Material 3 モダンインターフェース（動的カラー抽出対応）およびモダン／クラシック UI の切り替え機能。
  • 初回起動時オンボーディングガイド（デフォルトの Pixel XL 無制限バックアップの案内および 1 クリックでの強制停止・起動アクション）。
  • 特定の Google Pixel 端末プロファイルの偽装（Pixel XL、Pixel 6、Pixel Fold、Pixel Tablet、Pixel 9 Pro Fold から Pixel 10 シリーズまで計 30 種類を網羅）。
  • 各端末モデルに対応する特典バッジと必要なバックアップ画質警告をリアルタイム表示。
  • Pixel 関連のシステム機能フラグを偽装。
  • マルチティアの汎用フォールバックパイプライン（Android 8.0 から Android 14、15、16+ および各種カスタム OEM ROM に対応）。
  • 互換性のある Android バージョンを任意で偽装。
  • ROM が提供する Pixel feature level を上書き。
  • 詳細設定で個別の機能フラグを選択。
  • モジュール設定のインポート、エクスポート、共有。
  • アプリ内診断画面：モジュールの有効状態・バックアップ特典状態・フックのマイルストーン・直近のデバイス偽装 VERIFY 結果を logcat 不要で確認でき、アカウント情報を含まない診断レポートをコピー可能。

重要なお知らせ

主な目的が無料の無制限フォトストレージの獲得である場合は、必ず Pixel XL（元の画質）または Pixel 2 〜 Pixel 5a（画質設定を保存容量の節約画質に設定）を選択してください。Pixel 6 以降のモデルには無料容量は付与されません。

バックアップが成功したか確認する方法

端末偽装と無料バックアップが正常に動作しているかは以下の 2 つの方法で確認できます：

方法 1: Google フォトのバックアップ設定

  1. Google フォトを開きます。
  2. 右上のプロフィールアイコン > バックアップをタップ。
  3. 右上の歯車アイコン（バックアップ設定）をタップ。
  4. バナーに表示されているか確認：「この Pixel からは写真や動画を無料で無制限にバックアップできます」。

方法 2: アップロード写真の詳細情報を確認

  1. Google フォトで写真または動画を 1 枚バックアップします。
  2. その写真を開き、上にスワイプして詳細情報を確認します（または photos.google.com で確認）。
  3. ストレージ情報欄に表示されていることを確認：「このアイテムはアカウントの保存容量を使用しません」（0 バイト使用）。

トラブルシューティング：写真が容量を消費する場合は、アプリ内の「診断」画面で VERIFY が成功（OK）しているか確認し、Pixel 2〜5 では画質が保存容量の節約画質になっているか確認した上で、「スコープ内アプリを強制停止」または Google フォトのキャッシュ消去を行ってください。

要件

  • Android 8.0（API 26）以降。
  • Root 権限。
  • Modern libxposed API 101 をサポートする Xposed 環境（互換性のある LSPosed 構成など）。
  • Google フォト（com.google.android.apps.photos）。

この Modern API ビルドは、旧式の XposedBridge／EdXposed 環境には対応していません。 モジュールのスコープに Google フォトを含めてください（推奨）。 追加アプリは高度／非サポートでリスクがあります。Play サービス、Play ストア、システム UI／設定、 銀行／決済アプリはスコープしないでください （選択してもモジュールが soft-denylist する項目があります）。

インストール

  1. このリポジトリの Releases ページ（または公式 Xposed Modules Repository ミラー）から APK をダウンロードします。
  2. APK をインストールします。
  3. Xposed モジュールマネージャーで Pixelify Infinity を有効にします。
  4. モジュールのスコープに Google フォトを含めます（推奨）。 マルチアプリ スコープは可能ですが、追加アプリは高度／非サポートです。
  5. Play サービス、Play ストア、システム UI／設定、銀行／決済アプリはスコープしないでください。
  6. Google フォト（およびスコープした他アプリ）を強制停止して再度開きます。モジュールマネージャーから要求された場合は端末を再起動します。

インストール前に、署名者のフィンガープリントが docs/RELEASE_SIGNING.md で公開されている内容と一致することを確認してください。公式リリースは固定の署名証明書を使用します。秘密署名鍵はこのリポジトリでは配布されません。
