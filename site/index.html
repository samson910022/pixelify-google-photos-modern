Pixelify Infinity

An independently maintained Xposed module that spoofs selected Google Pixel device properties and system feature flags for Google Photos. Built on the modern libxposed API, with its own package name, release history, and signing identity.

GitHub Releases Xposed Modules Repo LSPosed listing
Important

This project is not affiliated with or endorsed by Google, Google Photos, Pixel, LSPosed, or the original upstream maintainers. Feature availability can change with Google Photos, server-side configuration, account, region, device, or Android updates. Use the module at your own risk.

Features

  • Modern Material 3 interface with dynamic Monet color extraction and dual UI toggle (seamlessly switch between Modern and Classic UI).
  • First-run onboarding guide explaining default Pixel XL unlimited backup with a 1-click force-stop & launch action.
  • Spoof selected Google Pixel device profiles (30 device profiles spanning Pixel XL, Pixel 6, Pixel Fold, Pixel Tablet, Pixel 9 Pro Fold, up to Pixel 10 series).
  • Real-time entitlement badges and quality requirement warnings for every device model.
  • Spoof Pixel-related system feature flags.
  • Multi-tier capability-driven write fallback pipeline supporting Android 8.0 through Android 14, 15, 16, and custom OEM ROMs.
  • Optionally spoof a compatible Android version.
  • Override ROM-provided Pixel feature levels.
  • Select individual feature flags through an advanced configuration screen.
  • Import, export, and share module configuration.
  • In-app Diagnostics screen: view module-active state, backup entitlement status, hook milestones, and the last device-spoof VERIFY result without logcat, and copy a sanitized report for issue reports.

Device Profiles & Backup Entitlements

Different Pixel hardware profiles provide different Google Photos backup entitlements under Google's cloud storage policies:

Profile Tier Models Backup Entitlement Required Quality Setting Unlocked Features
Unlimited Original Quality Pixel XL (Default) Unlimited free backup at Original Quality & Storage Saver (0 bytes quota used) Original quality or Storage saver Pixel 2016 base tier (stable unlimited backup; no Tensor AI editing tools)
Unlimited Storage Saver Only Pixel 2, Pixel 3 XL, Pixel 3a XL, Pixel 4 XL, Pixel 4a, Pixel 5, Pixel 5a Unlimited free backup at Storage Saver quality ONLY Storage saver ONLY (Original quality consumes account storage!) Mid-tier Pixel features
Editing Features Only Pixel 6 through Pixel 10 series, Pixel Fold, Pixel Tablet No free unlimited backup (Uploads consume Google Account storage quota) Google Account quota applies to all uploads Modern Pixel camera & AI editing tools (Magic Eraser, Ultra HDR, Photo Unblur, etc.)
Important

If your primary goal is free unlimited Google Photos storage, select Pixel XL (Original quality) or Pixel 2 through Pixel 5a (with quality set to Storage saver). Pixel 6 and newer models do not grant free backup quota.

How to Verify Unlimited Backup

Confirm that device spoofing and unlimited cloud backup are active using either method:

Method 1: In-App Backup Settings

  1. Open Google Photos.
  2. Tap profile avatar at top-right > Backup.
  3. Tap the gear icon (Backup settings) at top-right.
  4. Confirm the banner displays: "This Pixel can back up unlimited photos & videos at no charge."

Method 2: Upload & Storage Details

  1. Back up a new photo or video in Google Photos.
  2. Open the photo and swipe up to view details (or view details on photos.google.com).
  3. Confirm the storage line states: "This item doesn't take up space in your account storage" (0 bytes used).

Troubleshooting: If uploads still consume quota, open the in-app Diagnostics screen in Pixelify Infinity to confirm VERIFY is OK, check that your backup quality is set to Storage saver for Pixel 2–5 profiles, and use Force-stop scoped apps or clear Google Photos app cache.

Requirements

  • Android 8.0 (API 26) or later.
  • Root access.
  • An Xposed environment with modern libxposed API 101 support, such as a compatible LSPosed setup.
  • Google Photos (com.google.android.apps.photos).

Legacy XposedBridge / EdXposed environments are not supported by this modern-API build. Keep Google Photos in scope (recommended). Extra apps are advanced/unsupported and carry risk. Do not scope Play Services, Play Store, system UI/settings, or banking/payment apps (the module soft-denylists several of these even if selected).

Installation

  1. Download the APK from this repository’s Releases page (or the official Xposed Modules Repository mirror).
  2. Install the APK.
  3. Enable Pixelify Infinity in your Xposed module manager.
  4. Keep Google Photos in the module scope (recommended). Multi-app scope is allowed but extra apps are advanced/unsupported.
  5. Do not scope Play Services, Play Store, system UI/settings, or banking/payment apps.
  6. Force-stop and reopen Google Photos (and any other scoped apps). Reboot the device if the module manager requires it.

Before installing, verify the release signer fingerprint in docs/RELEASE_SIGNING.md. Official releases use a stable signing certificate; private keys are never distributed in the repository.

Upgrading from the legacy project

This project uses the independent application ID io.github.samson910022.pixelifyphotos.

It is a separate application, not an in-place upgrade of balti.xposed.pixelifygooglephotos. The two apps may coexist. When migrating, enable and scope the new module separately; settings are not migrated automatically.

See FORK_NOTICE.md for the complete maintenance and attribution notice.

Privacy

Pixelify Infinity does not include analytics or advertising SDKs. The app may use network access to check configured GitHub / Xposed release metadata for updates and to open project links. Module settings and exported configuration remain under your control.
